Reliable Solutions VI: email signature

  1. Open this file in a browser (Chrome works best with Gmail).
  2. Drag to select everything inside the dashed box below (or click Select signature), then copy it with Ctrl/Cmd + C.
  3. In Gmail, go to Settings → See all settings → General → Signature, create a new signature, and paste.
  4. Scroll to the bottom of that page and click Save Changes.

Before you paste for real: the images point to https://reliablesolutionsvi.com/business-card/assets/logo.png and https://reliablesolutionsvi.com/business-card/assets/qr-vcard.png. Gmail strips embedded (data:) and SVG images, so these must be public PNG links. Copy the signature from the live page at https://reliablesolutionsvi.com/business-card/email-signature.html once this folder is deployed, so the pasted images use those public links. When this file is opened anywhere else (e.g. locally), the images are shown from the local assets/ folder for preview only, so don't copy from a local copy.
